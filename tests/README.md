# Pruebas
Ejecuta `cd backend && npm test`. Esta primera entrega deja la infraestructura de pruebas lista; agrega pruebas de integración con una base de datos de test antes de producción. Casos obligatorios: autorización cruzada entre usuarios, MIME spoofing, path traversal, CSRF, revocación de sesiones, cuotas, recuperación y restauración de backups.
